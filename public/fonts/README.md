# Game UI fonts

The UI uses local Latin variable font subsets from Google Fonts:

- `baloo2-latin.woff2`: Baloo 2, weights 600–800, for headings and button labels.
- `nunito-latin.woff2`: Nunito, weights 500–900, for body text and counters.

Source stylesheet:
https://fonts.googleapis.com/css2?family=Baloo+2:wght@600..800&family=Nunito:wght@500..900&display=swap

Font binaries:
https://fonts.gstatic.com/s/baloo2/v23/wXKrE3kTposypRyd51jcAA.woff2
https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofINeaB.woff2

The original SIL Open Font License texts and copyright notices are included in
`baloo2-OFL.txt` and `nunito-OFL.txt`, from the corresponding `ofl` folders in
https://github.com/google/fonts.
